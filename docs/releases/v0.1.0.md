# Release v0.1.0 — 2026-07-16

First tagged evaluation snapshot of HunyuanOCR-ROCm. See
[docs/benchmark-methodology.md](../benchmark-methodology.md) for provenance and
comparability rules.

## Formal results

**Table A — same 148-page canary, three ROCm backends** (gfx1100, ROCm 7.2, bf16):

| Backend | Overall | text EditDist↓ | formula CDM↑ | table TEDS↑ | order EditDist↓ |
|---|---|---|---|---|---|
| vLLM 0.16.1 (Flash-Attn ViT) | 94.81 | 0.0514 | 0.9648 | 0.9308 | 0.1135 |
| transformers 5.13.0 (SDPA ViT) | 94.11 | 0.0437 | 0.9425 | 0.9246 | 0.1184 |
| llama.cpp (C++ GGML, BF16) | 93.33 | 0.0512 | 0.9083 | 0.9429 | 0.1270 |

**Table B — full 1651-page set** (OmniDocBench v1.6):

| Source | Overall | text | CDM | TEDS | Engine |
|---|---|---|---|---|---|
| llama.cpp (this repo) | 92.09 | 0.0467 | 0.8964 | 0.9130 | llama.cpp HIP |
| Official HunyuanOCR | 94.10 | 0.042 | 0.9473 | 0.9181 | TensorRT |

The −2.01 gap is **not** a ROCm-vs-CUDA delta (official uses TensorRT on an
unlabeled dataset version).

## Diagnostic / invalid results (NOT formal)

- **Invalid (excluded):** vLLM full-set 1651 = 46.31 — server crashes, ~780 ERROR
  pages. Excluded from all comparisons.
- **Diagnostic only:** >14k ViT NaN isolation, throughput tuning, formula-CDM
  ablation.

## Supported environment

- GPU: AMD gfx1100 (RDNA3, 48 GB) ×4 (1 sufficient for inference/canary).
- ROCm 7.2 (hip 7.2.53211-e1a6bc5663), torch 2.9.1+gitff65f5b (ROCm build).
- llama.cpp commit `a320cbfcb7056b7b81fb854d97fe01d0ea77c4b5` (ggml 0.16.0).
- Python 3.12. transformers 5.13.0 (benchmark venv); vLLM 0.16.1.dev0.

## Known limitations

- **Not precision-aligned** — no same-page-set CUDA control; official headline is
  TensorRT.
- vLLM full-set unstable under sustained load; transformers full-set impractical
  (~40 h).
- >14k vision-token NaN in the transformers/ROCm SDPA ViT path (capped at 3.4M px
  as a workaround; see ROCm#6416).
- Other RDNA3 / non-gfx1100 untested; minimum VRAM not measured.

## Reproduce

```bash
LLAMA_DIR=/path/to/llama.cpp GGUF_DIR=/path/to/HunyuanOCR-GGUF \
DATA_DIR=/path/to/OmniDocBench_data OUT_DIR=./predictions \
bash scripts/reproduce_llamacpp_canary.sh     # 148 pages
# or reproduce_llamacpp_full.sh for 1651
```

Pipeline: predict → validate → score → verify manifest, bound to `127.0.0.1`,
against the locked llama.cpp commit.
