# Getting help

- **Bugs / crashes** → [bug report](https://github.com/AIwork4me/HunyuanOCR-ROCm/issues/new?template=bug_report.yml).
- **ROCm / gfx compatibility** → [ROCm compatibility](https://github.com/AIwork4me/HunyuanOCR-ROCm/issues/new?template=rocm_compatibility.yml) (include GPU, gfx arch, ROCm, torch, llama.cpp/vLLM commit).
- **Score / benchmark questions** → [benchmark report](https://github.com/AIwork4me/HunyuanOCR-ROCm/issues/new?template=benchmark_report.yml).
- **Security** → see [SECURITY.md](SECURITY.md) (private reporting only).
- **Usage questions / discussion** → GitHub Discussions (if enabled) or open a generic issue.

Before filing, run `hunyuan-ocr doctor` and paste its output — it captures your
environment without loading the model.

This is a community project; responses are best-effort and not on an SLA.
